# Contributing

Thank you for taking an interest in the Queria CLI.

## Issues are welcome

Bug reports and feature requests are the most useful thing you can send us. Open an [issue](https://github.com/queria-io/queria-cli/issues/new/choose) — English and Japanese are both fine.

For a bug report, `queria --version` and your operating system make the difference between a fix and a guess.

## Pull requests are not accepted

The source of the client is included in every PyPI release so that you can read and audit it, but development happens in a private repository. There is nothing to send a pull request against, and we cannot merge one here.

If you have a concrete fix in mind, open an issue and describe it — a patch pasted into the issue body is welcome, and we will attribute it in the changelog if we use it.

## Security

Do not report security issues through public issues. See [SECURITY.md](SECURITY.md).
